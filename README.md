# SKYVEIL 크루 면접 신청 사이트

> WE CREATE THE NEXT STAR.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `app.js` | 지원자용 메인 페이지 (소개 · 모집 분야 · 절차 · 신청서 · FAQ) |
| `admin.html`, `admin.js` | 관리자 콘솔 (로그인 · 조회 · 검색 · 상태 변경 · 면접 일정 · 삭제) |
| `styles.css` | 공통 스타일 |
| `config.js` | 서버(API) 주소 설정 |
| `workers/skyveil-api-*.js` | 서버 코드 (지원서 저장 · 관리자 인증 · 권한 검사) |
| `assets/hero-sky.jpg` | 메인 배경 이미지 |

## 데이터 저장과 보안

- 지원서는 **서버(Puter 서버리스 워커)의 비공개 저장소**에 저장됩니다. 브라우저에는 저장되지 않습니다.
- 지원자는 **제출만** 가능하며, 지원서 조회 API는 존재하지 않습니다.
- 관리자 비밀번호는 코드에 적혀 있지 않고 서버의 비공개 저장소(`ADMIN_PASSWORD`)에만 보관됩니다.
- 로그인 성공 시 서버가 8시간짜리 무작위 세션 토큰을 발급하고, **조회 · 변경 · 삭제 요청마다 서버가 토큰을 검사**합니다. 토큰이 없거나 만료되면 401로 거부됩니다.
- 서버에서 모든 입력값의 길이 · 형식 · 허용값(분야, 상태, 연락 수단)을 다시 검증합니다.
- 관리자 화면은 출력 시 모든 값을 이스케이프하여 스크립트 삽입을 막습니다.

## 사용 방법

1. 메인 페이지 하단 **신청서**를 작성하고 제출 → 접수번호가 담긴 완료 안내가 표시됩니다.
2. 페이지 맨 아래 **관리자** 링크(또는 `/admin.html`)로 이동 → 비밀번호로 로그인합니다.
3. 지원서를 선택해 상태 변경, 면접 일정 등록, 메모 작성, 삭제를 할 수 있습니다.
4. **면접 일정** 탭에서 날짜별 일정을 한눈에 확인합니다.

## 배포

### 방법 1 · Puter에서 바로 공개 (권장)
빌더 미리보기의 **Publish** 버튼을 누르면 `*.puter.site` 주소로 공개됩니다.
서버와 관리자 비밀번호도 자동으로 함께 반영됩니다. 개인 도메인은 Publish 메뉴의 "Use custom domain"에서 연결할 수 있습니다(유료 플랜).

### 방법 2 · 다른 호스팅(Netlify, Vercel, GitHub Pages 등)
1. 서버 코드를 제외한 정적 파일(`index.html`, `admin.html`, `*.js`, `styles.css`, `icon.svg`, `assets/`)을 업로드합니다.
2. 서버는 Puter에서 그대로 동작하므로 `config.js`의 주소를 바꿀 필요가 없습니다.
3. 빌드 과정이 필요 없는 순수 HTML/JS 사이트입니다.

### 로컬에서 실행
```bash
npx serve .        # 또는  python -m http.server 8080
```
브라우저에서 `http://localhost:3000`(또는 8080)을 엽니다.

## 관리자 비밀번호 변경
빌더 채팅에서 "관리자 비밀번호를 ○○로 바꿔줘"라고 요청하면 서버 비공개 저장소의 값만 교체됩니다. 코드 수정이나 재배포가 필요 없습니다.

## Firebase에 관하여
이 빌드 환경에서는 Firebase 대신 Puter 서버리스 워커 + 비공개 저장소를 사용합니다.
"실제 서버 저장 · 서버 측 권한 검사 · 관리자 전용 열람"이라는 요구 사항은 동일하게 충족합니다.
